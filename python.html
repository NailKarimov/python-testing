Округление: почему нужен Hypothesis

Rounding: why Hypothesis

Скидка округляется до копеек «как на кассе» — половина вверх. Банковское округление отличается только когда остаток ровно половина копейки. Ни одна из семи вручную подобранных корзин такого не содержала, и посаженный баг M1 поймал только Hypothesis, сравнивающий сервис с независимым оракулом. Введите сумму и скидку.

The discount is rounded to cents the way a till does: half up. Banker's rounding differs only when exactly half a cent is left. None of the seven hand-picked baskets had that, and planted bug M1 was caught only by Hypothesis comparing the service with an independent oracle. Enter an amount and a discount.

Что Schemathesis нашёл в нашем же контракте

What Schemathesis found in our own contract

Schemathesis читает /openapi.json, который публикует сам сервис, генерирует запросы и проверяет ответы. Каждая находка — место, где опубликованный контракт обещал не то, что делает код.

Schemathesis reads the /openapi.json the service itself publishes, generates requests and checks the answers. Each finding is a place where the published contract promised something the code doesn't do.

Locust и одно соединение на всех

Locust and one connection for everyone

FastAPI выполняет обработчики в пуле потоков. Пока все потоки делили одно соединение SQLite, чтение рядом с записью иногда получало пустую строку — 500. Функциональные тесты ходят по одному запросу и этого не видят; 30 пользователей Locust увидели за полминуты.

FastAPI runs handlers in a thread pool. While every thread shared one SQLite connection, a read next to a write sometimes got an empty row: a 500. Functional tests send one request at a time and never see it; 30 Locust users saw it within half a minute.
